# 📋 Project Management

This project has been managed using a Kanban-inspired workflow, supported by a Trello board to organize and track development progress.

---

## 🧠 Methodology Used

I used a Kanban-based approach because it allows:

- Clear visualization of the workflow
- Breaking the project into small tasks
- Continuous progress tracking
- Flexible prioritization of tasks

---

## 📌 Board Structure

The Trello board is divided into the following columns:

- **Backlog** → future or unprioritized tasks
- **Todo** → tasks ready to be developed
- **In Progress** → tasks currently being worked on
- **Review** → completed tasks pending review
- **Done** → finished tasks

---

## 🛠️ Work Organization

Each project feature is split into individual cards to ensure a structured development process.

Example task cards:

- Project setup (Vite + React + TypeScript)
- Tailwind CSS installation and configuration
- Folder structure creation
- Core component development
- Implementation of Top 5 lists functionality
- React Router setup
- Controlled forms implementation
- State management using useState

Each card includes smaller technical subtasks to make development more manageable and incremental.

---

## 🔄 Workflow

1. Tasks are created in the **Backlog**
2. They are prioritized and moved to **Todo**
3. Tasks move to **In Progress** when development starts
4. Completed tasks move to **Review**
5. Finally, they are marked as **Done**

---

## 🎯 Project Goal

The main goal of this organization is to maintain a clean and structured workflow, avoid blockers, and ensure that all project features are developed progressively and efficiently.
